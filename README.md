# Baibolintsika — Assistance et confidentialité

Site statique public pour Baibolintsika et BaibolintsikaVerse.

- `index.html` : assistance commune, avec les instructions de BaibolintsikaVerse.
- `confidentialite-verse.html` : politique de confidentialité dédiée à l’extension.
- `confidentialite.html` : choix de la politique de chaque produit ; conserve le lien existant de l’application Baibolintsika.

Hébergement GitHub Pages depuis la branche principale, dossier racine. Les fichiers HTML et le logo sont les seules ressources nécessaires. Aucun script, dépendance distante, publicité ou outil d’analyse ajouté.
